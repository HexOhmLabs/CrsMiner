# CRSminer PC v0.2.3 — Windows SHA-256d CPU miner

[English README](README.md) · [Αλλαγές έκδοσης](CHANGELOG.md) · [Κεντρικό HexOhm CRSminer](../../README_GR.md)

**Πραγματικό mining SHA-256d σε Windows x64**, με έμφαση στην αξιοποίηση παλιών laptop και υπολογιστών. Πρόκειται για **miner**, όχι για την ξεχωριστή εφαρμογή παρακολούθησης στόλου (Fleet Monitor). Η εξόρυξη γίνεται για εκπαίδευση και πειραματισμό, όχι ως υπόσχεση κέρδους.

Η έκδοση δοκιμάστηκε από τον δημιουργό σε **AMD Ryzen 3 3200U** (SHA-NI) και **AMD E-350** (scalar C). Και οι δύο υπολογιστές έκαναν πραγματικό mining με αποδεκτά shares και εμφανίστηκαν στον browser Fleet Scanner.

## Δυνατότητες

- **Stratum V1 / SHA-256d**, σύνδεση σε συμβατό pool, λήψη jobs, έλεγχος και υποβολή shares.
- Αυτόματη επιλογή **SHA-NI / AVX2 / scalar C** ανάλογα με τον επεξεργαστή.
- Ανεξάρτητη ρύθμιση **0–100% ανά λογικό CPU**, με τουλάχιστον έναν CPU στο **75% ή χαμηλότερα** και τουλάχιστον έναν ενεργό worker.
- **Background**: κάτω από κανονική προτεραιότητα στα Windows. **Dedicated**: κανονική προτεραιότητα με CPU affinity. Δεν αποκλείονται kernel, υπηρεσίες, interrupts ή λειτουργίες των Windows.
- Σκούρο/ανοιχτό θέμα, γράφημα hashrate, στοιχεία pool, Start/Stop και **Ctrl+Shift+Q** όταν το παράθυρο είναι ενεργό.
- Προαιρετική καταγραφή **CSV diagnostics**, κουμπί ανοίγματος φακέλου και κουμπί εκκαθάρισης με επιβεβαίωση (μόνο όταν έχει σταματήσει το mining).
- Τοπικό **Fleet API** στη διεύθυνση `http://IP_ΥΠΟΛΟΓΙΣΤΗ:8080/api/status`.

## Αυτόματο worker στο pool — v0.2.3

Στις Ρυθμίσεις καταχωρίστε το wallet ή όνομα λογαριασμού στο **Wallet / pool account** και ξεχωριστά το **Worker name**. Εάν το wallet **δεν περιέχει τελεία**, η εφαρμογή προσθέτει αυτόματα `.worker`. Εάν υπάρχει ήδη τελεία, διατηρεί ακριβώς το κείμενο που γράψατε, χωρίς νέα κατάληξη. Ισχύει τόσο στο `mining.authorize` όσο και στο `mining.submit`.

| Wallet / pool account | Worker | Πραγματικό login στο pool |
|---|---|---|
| `TO_WALLET_SAS` | `pc01` | `TO_WALLET_SAS.pc01` |
| `TO_WALLET_SAS` | `pc02` | `TO_WALLET_SAS.pc02` |
| `TO_WALLET_SAS.custom` | `pc02` | `TO_WALLET_SAS.custom` |

Ο κωδικός pool αποστέλλεται χωρίς αλλαγές. Το αποθηκευμένο πεδίο wallet δεν τροποποιείται.

## Δημιουργία EXE σε Windows

Το repository περιλαμβάνει **ολόκληρο τον πηγαίο κώδικα**, την native Windows x64 DLL για SHA-256d, τους ελέγχους και το `BUILD_WINDOWS.bat`. **Δεν περιλαμβάνει έτοιμο EXE.**

1. Κατεβάστε **όλον τον φάκελο** του PC miner και αποσυμπιέστε τον διατηρώντας τη δομή του.
2. Εγκαταστήστε **Python 3.11+ 64-bit** στον υπολογιστή κατασκευής.
3. Εκτελέστε το `BUILD_WINDOWS.bat`. Δημιουργεί ξεχωριστό περιβάλλον, εγκαθιστά PyInstaller, εκτελεί tests και benchmark και κατασκευάζει το EXE.
4. Εκτελέστε το `dist\HexOhm_CRSminer_PC_v0.2.3.exe`. Στον υπολογιστή χρήσης δεν χρειάζεται Python.
5. Αν εμφανιστεί προειδοποίηση των Windows για το μη υπογεγραμμένο EXE, επαληθεύστε την προέλευση. Μην απενεργοποιείτε το antivirus ή άλλες προστασίες των Windows.

Το `BENCH_WINDOWS.bat` εκτελεί δοκιμές ταχύτητας χωρίς σύνδεση σε pool. Το `RUN_SOURCE_WINDOWS.bat` εκκινεί τον πηγαίο κώδικα.

## Ρυθμίσεις, diagnostics και παρακολούθηση

- Αρχείο ρυθμίσεων: `%LOCALAPPDATA%\HexOhm\CRSminerPC\config_v023.json`.
- Κατά την πρώτη εκκίνηση μπορούν να εισαχθούν οι προηγούμενες ρυθμίσεις v0.2.2, DIAG2 ή παλαιότερες **μόνο για ανάγνωση**.
- CSV αρχεία: `%LOCALAPPDATA%\HexOhm\CRSminerPC\diagnostics\`.
- Η απενεργοποίηση της καταγραφής δεν διαγράφει παλαιότερα CSV. Η εκκαθάριση ζητά επιβεβαίωση και γίνεται μόνο μετά το Stop.
- Για τον Fleet Scanner, προσθέστε `IP_ΥΠΟΛΟΓΙΣΤΗ:8080`. Η ένδειξη `crsminer-XXXX.local` στο API είναι **συμβατική ετικέτα**, όχι κατοχύρωση ονόματος mDNS.

## Ασφάλεια και περιορισμοί

Ο κωδικός pool αποθηκεύεται **χωρίς κρυπτογράφηση** στο τοπικό JSON. Μην ανεβάζετε ρυθμίσεις, προσωπικά diagnostics ή logs στο GitHub. Το Fleet API στη θύρα 8080 δεν έχει κωδικό ή TLS· επιτρέπεται μόνο σε **έμπιστο τοπικό δίκτυο**, ποτέ μέσω port forwarding στο Internet. Το mining καταπονεί τη CPU· παρακολουθείτε θερμοκρασία και συχνότητα. Το 75% effort δεν εγγυάται διαθέσιμο χρόνο CPU στις άλλες εφαρμογές. Οι προστασίες των Windows και της CPU δεν πρέπει να παρακάμπτονται.

## Έλεγχοι και άδεια

Οι πραγματικές δοκιμές σε δύο laptop επιβεβαίωσαν mining, αποδεκτά shares και Fleet Scanner. Ο τοπικός έλεγχος της διανομής πέρασε **και τις 37 δοκιμές Python**, μαζί με τους native SHA-256d ελέγχους. Το EXE πρέπει να κατασκευαστεί σε Windows και δεν είναι υπογεγραμμένο.
