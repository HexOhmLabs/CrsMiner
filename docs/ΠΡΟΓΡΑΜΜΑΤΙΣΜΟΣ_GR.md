# Εγκατάσταση CRSminer με browser — ελληνικές οδηγίες

Οδηγίες για τα **δύο συγκεκριμένα τελικά builds** (ESP32 και CYD). Χρησιμοποιήστε το [ESP Web Tool](https://esptool.spacehuhn.com/) από υπολογιστή με Chrome ή Edge και καλώδιο USB δεδομένων.

**Απλή εγκατάσταση:** επιλέξτε το σωστό αρχείο `HexOhm_CRSminer_ESP32_Final_Merged.bin` ή `HexOhm_CRSminer_CYD_Final_Merged.bin`, ορίστε διεύθυνση **`0x0000`** και πατήστε **Program**. **ΠΡΟΣΟΧΗ:** το merged αρχείο των 4 MB ξαναγράφει όλη τη flash και μπορεί να σβήσει τις αποθηκευμένες ρυθμίσεις Wi-Fi, pool και wallet.

**Εγκατάσταση με ξεχωριστά αρχεία:** προσθέστε **αποκλειστικά τα τέσσερα αρχεία της αντίστοιχης πλακέτας** με διευθύνσεις:

- Bootloader: **`0x1000`**
- Partition table: **`0x8000`**
- `boot_app0.bin`: **`0xE000`**
- Application `.bin`: **`0x10000`**

Οι δύο πλακέτες έχουν **διαφορετικό partition table**· μην αναμειγνύετε τα αρχεία τους. Για τα ακριβή ονόματα, τις επιπλέον λεπτομέρειες και τις προειδοποιήσεις, διαβάστε τον [αναλυτικό οδηγό στα αγγλικά](FLASHING.md).
