# Λίστα ελέγχου πριν από δημοσίευση στο GitHub

[English version](RELEASE_CHECKLIST.md)

1. Χρησιμοποιήστε το υπάρχον δημόσιο repository **`HexOhmLabs/CrsMiner`**. Σε ενημερώσεις κρατήστε τα υπάρχοντα `README.md` και `LICENSE` και ελέγξτε τις αλλαγές πριν από commit.
2. Ανεβάστε **τα περιεχόμενα** του ZIP, όχι το ίδιο το ZIP στη θέση του repository. Διατηρήστε τη δομή φακέλων και τα κρυφά `.github` αρχεία. Αν χρησιμοποιείτε patch, βεβαιωθείτε ότι περιέχει **όλα** τα αρχεία που προσθέτει και ότι δεν μένουν παλιοί/διπλοί φάκελοι.
3. Ελέγξτε README, άδειες χρήσης, ότι όλοι οι σύνδεσμοι λειτουργούν και ότι **δεν** έχουν προστεθεί προσωπικά στοιχεία ή credentials.
4. Δημιουργήστε GitHub **Release** (ενδεικτικό όνομα `CRSminer — Initial Public Release`) και επισυνάψτε τα κατάλληλα merged binaries ESP32/CYD. Παραπέμψτε στις [οδηγίες flashing](FLASHING_GR.md), στα επιμέρους αρχεία και στον [οδηγό Raspberry Pi](../firmware/Raspberry_Pi_USB_ASIC/README_GR.md). Το Pi **δεν** χρησιμοποιεί `.bin` ESP32.
5. Διατηρήστε **ολόκληρο το Android CPU mining source** και ξεχωριστά το Android Monitor. Το παρεχόμενο APK του Android miner είναι **debug**. Πριν από παραγωγική διανομή χρειάζεται ξεχωριστό υπογεγραμμένο APK και έλεγχος. Για monitor προτείνεται η **v1.2**· η **v1.3** παρέχεται μόνο ως προαιρετικό development source.
6. Κάντε πρακτική δοκιμή εγκατάστασης σε εφεδρική συμβατή πλακέτα προτού γενικεύσετε ισχυρισμούς για άλλες πλακέτες. Φυλάξτε τις ρυθμίσεις των ενεργών miners.
7. Για αναφορές προβλημάτων στο GitHub Issues ζητήστε logs **χωρίς** Wi-Fi passwords, ιδιωτικά κλειδιά, στοιχεία pool και προσωπικές IP/MAC.
8. Μετά το ανέβασμα επιθεωρήστε την κεντρική σελίδα, εικόνες και συνδέσμους και στις **δύο γλώσσες**.
