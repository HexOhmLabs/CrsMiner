# CRSminer ESP32 — Οδηγός εγκατάστασης και χρήσης

[English version](ESP32_USER_GUIDE.md) · [Κεντρική σελίδα στα ελληνικά](../README_GR.md)

**Αφορά:** το δημοσιευμένο firmware **CRSminer-14** για την κλασική πλακέτα ESP32 με flash 4 MB. Οι παρούσες οδηγίες εξηγούν τη χρήση του ήδη διαθέσιμου firmware, χωρίς καμία μεταβολή στον κώδικά του. Για τις διευθύνσεις προγραμματισμού δείτε τον [οδηγό flashing](FLASHING_GR.md).

## 1. Εγκατάσταση του firmware

1. Κατεβάστε το σωστό [merged αρχείο για ESP32](../firmware/ESP32/merged/HexOhm_CRSminer_ESP32_Final_Merged.bin). **Μην επιλέξετε το αρχείο CYD.**
2. Συνδέστε την πλακέτα με καλώδιο USB **που μεταφέρει δεδομένα** και ανοίξτε το [ESP Web Tool](https://esptool.spacehuhn.com/) σε Chrome ή Edge υπολογιστή.
3. Για το πλήρες merged αρχείο των 4 MiB ορίστε **διεύθυνση `0x0000`** και πραγματοποιήστε τον προγραμματισμό. Αν προτιμάτε ξεχωριστά αρχεία bootloader/partitions/application, δείτε [FLASHING_GR.md](FLASHING_GR.md).
4. Επανεκκινήστε την πλακέτα.

**Προσοχή:** Η εγκατάσταση ολόκληρου merged image αντικαθιστά το περιεχόμενο της flash και **διαγράφει τις αποθηκευμένες ρυθμίσεις**. Τα binaries ESP32 και CYD δεν είναι εναλλάξιμα.

## 2. Αρχική ρύθμιση Wi-Fi, pool και worker

Όταν λείπουν έγκυρο όνομα miner ή στοιχεία διεύθυνσης πορτοφολιού, το WiFiManager δημιουργεί ασύρματο δίκτυο **`CRSminer-Setup`** ή **`CRSminer-NAME-Setup`**, αν έχει ήδη οριστεί τετραψήφιο/τετραγράμματο όνομα.

1. Συνδεθείτε σε αυτό το Wi-Fi από κινητό ή υπολογιστή.
2. Ανοίξτε την αυτόματη σελίδα ρυθμίσεων (captive portal). Αν δεν εμφανιστεί, δοκιμάστε το συνήθες **`http://192.168.4.1`** όσο παραμένετε συνδεδεμένοι στο δίκτυο ρυθμίσεων.
3. Επιλέξτε το κανονικό σας Wi-Fi και εισαγάγετε τον κωδικό του.
4. Συμπληρώστε τις παραμέτρους mining:

   | Πεδίο | Τι σημαίνει |
   |---|---|
   | **Miner name** | Ακριβώς **4 λατινικά γράμματα/ψηφία**, π.χ. `rig1`. Η διεύθυνση γίνεται `crsminer-rig1.local`. |
   | **Pool URL** | Συμβατό SHA-256d / Stratum V1 pool, μορφή `host:port`. |
   | **Wallet address** | Διεύθυνση πληρωμών του νομίσματος που υποστηρίζει το συγκεκριμένο pool. |
   | **Worker name** | Όνομα worker· προεπιλογή `crs`, αν μείνει κενό. |
   | **Pool password** | Ό,τι ορίζει το pool, συχνά `x`. |
   | **Suggested difficulty** | Προαιρετική δυσκολία, εφόσον την υποστηρίζει το pool· αφήστε κενό για την προεπιλογή. |
   | **Blue LED / LED GPIO** | Τρόπος λειτουργίας και pin της ενδεικτικής LED. |
   | **Language** | Αγγλικά / Ελληνικά στο περιβάλλον. |

5. Αποθηκεύστε τις ρυθμίσεις. Ο miner συνδέεται στο Wi-Fi και στο pool και συνεχίζει μετά τους αρχικούς ελέγχους SHA.

Η σύνδεση Wi-Fi **δεν αποδεικνύει από μόνη της** επιτυχή εξόρυξη. Ελέγχετε σύνδεση με pool, hashrate και accepted shares. Μην κοινοποιείτε κωδικούς Wi-Fi/pool σε screenshots ή ζητήματα GitHub.

## 3. Web dashboard — καθημερινή χρήση

Από συσκευή **στο ίδιο τοπικό δίκτυο**, ανοίξτε:

- `http://crsminer-rig1.local` (αντικαταστήστε το `rig1` με το όνομα που ορίσατε), ή
- `http://<IP-του-miner>` αν η επίλυση του `.local` δεν λειτουργεί.

Η οθόνη δείχνει συνολικό και ανά πυρήνα **hashrate**, accepted/rejected shares, uptime, best difficulty, δυσκολία pool, κατάσταση Wi-Fi/pool και SHA engine, **Diagnostics**, **Event log** και γράφημα hashrate πέντε λεπτών. Στο **Settings** αλλάζετε όνομα, pool, wallet, worker, δυσκολία, LED και γλώσσα. Το **Save & reboot** αποθηκεύει τις αλλαγές και επανεκκινεί.

Το **Reset WiFi** διαγράφει τα στοιχεία Wi-Fi και επιστρέφει σε ρύθμιση δικτύου· **δεν είναι πλήρες factory reset**.

Για τους τοπικούς fleet monitors υπάρχει το read-only endpoint **`http://<IP-του-miner>/api/status`**. **Μην εκθέτετε το web dashboard στο δημόσιο Διαδίκτυο** με port forwarding.

## 4. Μπλε LED — Normal, Off και Diagnostic

Η ρύθμιση γίνεται από το αρχικό portal ή το web dashboard. Στον κλασικό ESP32 η προεπιλογή είναι **GPIO2**, αλλά **δεν έχουν όλες οι πλακέτες LED σε αυτό το pin**. Επιλέξτε το πραγματικό, κατάλληλο GPIO της συσκευής σας. Η τιμή **`-1`** σημαίνει ότι δεν χρησιμοποιείται ενδεικτική LED. Η πολικότητα (active HIGH/LOW) εξαρτάται από το hardware.

| Επιλογή | Πραγματική συμπεριφορά firmware |
|---|---|
| **On (προεπιλογή)** | Ο κώδικας αφήνει το επιλεγμένο GPIO LED χωρίς επιβολή διαγνωστικού μοτίβου. **Δεν εγγυάται συνεχώς αναμμένη LED.** |
| **Off** | Σβήνει τη διαμορφωμένη LED και καταστέλλει τα συνήθη περιοδικά μηνύματα της σειριακής εξόδου. |
| **Diagnostic** | Για περίπου **20 δευτερόλεπτα από την εκκίνηση** αναβοσβήνει, εφόσον δεν έχει εντοπιστεί πρόβλημα. Στη συνέχεια μένει **σβηστή** όταν όλα είναι εντάξει. Αν υπάρχει επίμονο πρόβλημα, μένει **σταθερά αναμμένη** μέχρι να λυθεί. |

**Σταθερά αναμμένη LED στο Diagnostic = απαιτείται έλεγχος**, όχι απαραίτητα ότι σταμάτησε η συσκευή. Δείτε **Diagnostics** και **Event log** για την αιτία. Ελέγχονται: αποτυχία SHA self-test, απώλεια Wi-Fi, μη διαθέσιμο pool, απόρριψη σύνδεσης/εξουσιοδότησης, απουσία hashing, πολλά rejected shares ή ασυνήθιστα μεγάλη περίοδος χωρίς accepted share. Υπάρχουν διαφορετικές χρονικές καθυστερήσεις ανά σφάλμα ώστε να αγνοούνται στιγμιαίες διακοπές.

**Σβηστή LED μετά την εκκίνηση στο Diagnostic είναι φυσιολογική** — δεν αποτελεί ένδειξη ότι το mining σταμάτησε.

## 5. Αλλαγή ρυθμίσεων και επαναφορά

- **Αλλαγή pool, worker, wallet ή LED:** `Settings → Save & reboot`.
- **Μόνο επαναφορά Wi-Fi:** `Reset WiFi` στο dashboard. Οι ρυθμίσεις mining μπορεί να παραμείνουν.
- **Εργοστασιακή επαναφορά:** Κρατήστε πατημένο το **BOOT κατά την τροφοδότηση** για **περισσότερα από 3 δευτερόλεπτα** (στον κλασικό ESP32 το BOOT χρησιμοποιεί GPIO0). Διαγράφονται ρυθμίσεις WiFiManager και miner και ακολουθεί επανεκκίνηση. Θα απαιτηθεί νέα ρύθμιση.

Το BOOT κατά την αρχική εκκίνηση για factory reset είναι **διαφορετική διαδικασία** από τη χρήση BOOT/RESET για εισαγωγή σε λειτουργία flashing.

## 6. Αντιμετώπιση προβλημάτων

| Σύμπτωμα | Έλεγχος |
|---|---|
| Δεν εμφανίζεται `CRSminer-Setup` | Τροφοδοσία, USB, σειριακή έξοδος **115200 baud**· ίσως υπάρχουν ήδη αποθηκευμένες ρυθμίσεις και η πλακέτα συνδέθηκε στο Wi-Fi σας. |
| Δεν ανοίγει το `.local` | Χρησιμοποιήστε την πραγματική IP από το router ή το serial monitor· ελέγξτε ότι είστε στο ίδιο LAN. |
| Υπάρχει Wi-Fi αλλά όχι mining | Ελέγξτε pool host/port, wallet/worker, εξουσιοδότηση και Diagnostics. |
| Η διαγνωστική LED δεν σβήνει | Διαβάστε την **ακριβή αιτία** στην ιστοσελίδα· η LED δείχνει ότι απαιτείται προσοχή, όχι ποιο σφάλμα υπάρχει. |
| Η LED δεν υπάρχει ή λειτουργεί ανάποδα | Ελέγξτε GPIO, πολικότητα και αν η τιμή είναι `-1`. |
| Απρόσμενες επανεκκινήσεις | Ελέγξτε τροφοδοσία, καλώδιο USB και το ιστορικό συμβάντων/αιτιών επανεκκίνησης. |
