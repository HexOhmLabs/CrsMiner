# Ασφάλεια, ιδιωτικότητα και πολιτική εικόνων

[English version](SECURITY_AND_PRIVACY.md)

Οι εικόνες δημοσίευσης έχουν υποστεί θόλωση ή περικοπή ώστε να μην εμφανίζονται πραγματικές τοπικές IP, MAC και διευθύνσεις πορτοφολιού. Οι καλλωπισμένες εικόνες hardware είναι **εικαστικές παρουσιάσεις** βασισμένες στις πραγματικές συσκευές, **όχι σχέδια καλωδίωσης**. Ο χρήστης συμπληρώνει τα δικά του στοιχεία Wi-Fi και mining.

- **Μη δημοσιεύετε** το προσωπικά συμπληρωμένο `crsminer.txt`, κωδικούς Wi-Fi/pool, ιδιωτικά κλειδιά wallet, προσωπικές διευθύνσεις IP/MAC, logs με μυστικά ή το τοπικό `known_miners.json`.
- Ένα binary firmware μπορεί να αποκαλύπτει strings που μπήκαν κατά τη μεταγλώττιση. Τα παρεχόμενα merged images δεν φέρουν προσωπική ρύθμιση στην περιοχή NVS· μετά από πλήρη εγκατάσταση απαιτείται νέα ρύθμιση.
- Το web configuration και τα APIs των miners προορίζονται για **ιδιωτικά, έμπιστα τοπικά δίκτυα**. **Μην ανοίγετε τις θύρες 80/8080 στο Internet** χωρίς κατάλληλη προστασία.
- Τυχόν ετικέτες στοιχείων/ακροδεκτών στις καλλωπισμένες εικόνες **δεν** αποτελούν έγκυρο pinout ή οδηγία σύνδεσης.
- Σε ζητήματα GitHub και αναφορές ευπαθειών αφαιρέστε credentials, endpoints και στοιχεία που ταυτοποιούν το προσωπικό σας δίκτυο.
