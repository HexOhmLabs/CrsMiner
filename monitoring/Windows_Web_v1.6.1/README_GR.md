# CRS Mining Web v1.6.1 — Ασφαλής παρακολούθηση

[English — README_FIRST.txt](README_FIRST.txt) · [Οδηγός monitoring](../../docs/MONITORING_GR.md)

**Δοκιμασμένη/προτεινόμενη έκδοση v1.6.1.** Διαβάζει στοιχεία ESP CRSminer στη θύρα **80** και συμβατού Android CPU miner στη θύρα **8080**, χωρίς να ελέγχει ή να αλλάζει τις ρυθμίσεις τους. Εμφανίζει τους miners από browser με τοπική γέφυρα Python.

## Εκκίνηση στα Windows

1. Κλείστε οποιοδήποτε παλαιότερο CRS Mining Web (και το παλιό παράθυρο Python).
2. Αποσυμπιέστε **ολόκληρο** τον φάκελο της v1.6.1 σε **νέα τοποθεσία**.
3. Προαιρετικά, αντιγράψτε το `known_miners.json` της παλαιότερης εγκατάστασης δίπλα στο `crs_bridge.py` για να διατηρήσετε IP/θύρες συσκευών. Δεν αποθηκεύει passwords ή wallets.
4. Με εγκατεστημένη **Python 3.9+**, κάντε διπλό κλικ στο **`START_CRS_MINING_WEB.bat`**.
5. Αν δεν ανοίξει αυτόματα, επισκεφθείτε **`http://127.0.0.1:8765/`**.
6. Οι γνωστοί miners παρακολουθούνται **χωρίς νέα πλήρη σάρωση LAN**. Για νέα IP, χρησιμοποιήστε **`+ Add miner`** ή, αν χρειάζεται, **μία** χειροκίνητη **`Scan network`** (με επιβεβαίωση και cooldown δύο λεπτών).

## Γιατί η v1.6.1

Παλαιότερες εκδόσεις χρησιμοποιούσαν πιο επιθετική ή αυτόματη ανακάλυψη. Παρατηρήθηκαν διαγνωστικές ενδείξεις και επανεκκινήσεις σε κάποιους ESP, χωρίς να έχει αποδειχθεί οριστικά η αιτία. Η v1.6.1 επιλέχθηκε για **συντηρητική συμπεριφορά**.

- **Χωρίς** πλήρη σάρωση subnet στην εκκίνηση ή περιοδικά.
- Οι αποθηκευμένες online συσκευές ερωτώνται διαδοχικά και κλιμακωτά, συνήθως όχι συχνότερα από **κάθε 12 δευτερόλεπτα**.
- Οι offline συσκευές έχουν αυξανόμενα διαστήματα επανάληψης, μέχρι περίπου **120 δευτερόλεπτα**.
- Το χειροκίνητο full scan χρησιμοποιεί **το πολύ δύο συνολικές συνδέσεις**, και το πολύ ένα request προς κάθε host ταυτόχρονα. Το κανονικό polling παγώνει κατά τη διάρκεια scan.
- **Μόνο μία HTTP GET** στη `/api/status` ανά endpoint για discovery· **χωρίς** προκαταρκτική γυμνή TCP σύνδεση. Τα όρια είναι περίπου **0,30 s connect** και **1,55 s response**, με `Connection: close`.
- Σε scan **δεν** ζητείται `/api/config`. Worker και wallet αποκτώνται μόνο όταν ανοίξετε λεπτομέρειες ενός miner, με σύντομο cache.
- Μόνο ιδιωτικές RFC1918 IPv4 διευθύνσεις, έως τρία τοπικά `/24` ή ρητά αποθηκευμένες IP, στις θύρες 80/8080.
- Η υπηρεσία Python ακούει μόνο στο **localhost:8765**, χωρίς επιπλέον Python packages.

## Αντιμετώπιση προβλημάτων

- Βεβαιωθείτε πρώτα ότι οι miners δουλεύουν **χωρίς** ανοικτό monitor, από LED/dashboard/pool shares.
- Μετά την εκκίνηση δώστε λίγο χρόνο: το polling είναι κατανεμημένο.
- Για συσκευή γνωστής IP, **`+ Add miner → Test connection`** αντί πλήρους scan. Για Android καταχωρίστε `:8080`.
- Αν λείπει worker ή wallet από πλακίδιο, ανοίξτε τις λεπτομέρειες· το monitor αποφεύγει τα περιττά μαζικά αιτήματα.
- Αν εμφανιστούν διαγνωστικά LED ή σταματήσουν τα shares μετά την εκκίνηση του monitor, **κλείστε τον web server** και καταγράψτε το `diag` από το `/api/status` εφόσον είναι διαθέσιμο. Μην επαναλαμβάνετε συνέχεια scans.
- Σε λανθασμένη IP ελέγξτε απομόνωση client Wi-Fi, subnet και αν οι miners απαντούν στη σωστή θύρα.

**Δεν τροποποιείται** firmware, Android mining engine ή Android monitor. Η v1.6.1 διατηρεί το dark/light UI, επιλογές layout και συμβατότητα status API.
