# CRSminer Fleet Scanner — Οδηγίες στα ελληνικά

[Κεντρική σελίδα](../../README_GR.md) · [Άνοιγμα HTML αρχείου](CRSminer-Fleet-Scan.html)

Το **`CRSminer-Fleet-Scan.html`** είναι αυτόνομο εργαλείο browser για την παρακολούθηση τοπικού στόλου CRSminer. Περιλαμβάνει ελληνικό/αγγλικό περιβάλλον, hashrate, shares, διαγράμματα, διατάξεις καρτών και αποθήκευση γνωστών συσκευών.

## Υποστηριζόμενοι miners

- **ESP32 / CYD:** HTTP API `http://IP:80/api/status` (στη λίστα αρκεί η διεύθυνση `IP`).
- **CRSminer for Android (CPU):** HTTP API `http://IP:8080/api/status` (στη λίστα χρειάζεται **`IP:8080`**).

Ο miner του κινητού πρέπει να είναι ενεργός, συνδεδεμένος στο ίδιο τοπικό δίκτυο Wi-Fi και να επιτρέπει τις συνδέσεις του status server. Ο browser πρέπει επίσης να επιτρέπει αιτήματα HTTP προς το LAN.

## Προσθήκη χειροκίνητα — η πιο άμεση δοκιμή

1. Ανοίξτε το HTML αρχείο στον browser και πατήστε **Miners**.
2. Στο πεδίο της λίστας εισαγάγετε μία συσκευή ανά γραμμή, προαιρετικά με ετικέτα:

   ```text
   192.168.1.40 ESP32
   192.168.1.41:8080 Android Phone
   ```

3. Πατήστε **Save** για να αρχίσει η παρακολούθηση. Οι διευθύνσεις είναι ενδεικτικές: χρησιμοποιήστε τις πραγματικές IP των συσκευών σας.

Αν δεν εμφανιστεί το Android miner, δοκιμάστε από το ίδιο PC να ανοίξετε απευθείας τη διεύθυνση `http://IP_ΚΙΝΗΤΟΥ:8080/api/status`. Θα πρέπει να επιστρέφει JSON. Το γεγονός ότι μια εφαρμογή Android μπορεί να ανακαλύψει τον miner δεν σημαίνει ότι ο browser έχει την ίδια πρόσβαση.

## Αυτόματη σάρωση ESP32 και Android

1. Πατήστε **Miners** ή **Scan network**.
2. Ορίστε το πρόθεμα δικτύου, π.χ. `192.168.1`, και το εύρος τελευταίου αριθμού IP (π.χ. 1–254).
3. Επιλέξτε λειτουργία: **ESP32 + Android (80 + 8080)**, **Μόνο ESP32 (80)** ή **Μόνο Android (8080)**.
4. Πατήστε **Scan** (αν δεν έχει ήδη ξεκινήσει από το κουμπί Scan network).
5. Οι miners που αναγνωρίζονται προστίθενται στη λίστα με την **πραγματική διεύθυνση και τη σωστή θύρα**. Πατήστε **Save** για να παραμείνουν αποθηκευμένοι.

Η σάρωση εξετάζει κάθε επιλεγμένο συνδυασμό IP και θύρας **μία φορά**, με έως οκτώ παράλληλες εργασίες, όπως στην προηγούμενη έκδοση. Η επιλογή και των δύο θυρών αυξάνει τον συνολικό αριθμό ελέγχων. Για γρήγορη διάγνωση κινητού, προτιμήστε **Μόνο Android (8080)** και μικρό εύρος IP. Μην επαναλαμβάνετε πλήρη σάρωση άσκοπα, ώστε να μην επιβαρύνονται οι μικροί HTTP servers των ESP32.

## Περιορισμοί browser

- Αν ανοίξετε την HTML σελίδα από `https://`, ο browser μπορεί να αποκλείσει τις `http://` συσκευές (mixed content). Προτιμήστε άνοιγμα του HTML τοπικά, όπου επιτρέπεται, ή φιλοξενία από τοπικό `http://` server.
- Οι κανόνες **CORS** και **Local Network Access** διαφέρουν ανά browser. Το Android CPU miner περιλαμβάνει `Access-Control-Allow-Origin: *`, αλλά πολιτικές του browser ή του δικτύου μπορούν παρόλα αυτά να εμποδίσουν την επικοινωνία.
- Το πρόγραμμα δεν διαβάζει απευθείας τις διευθύνσεις των συσκευών από το router. Η ανακάλυψη γίνεται με προσπάθειες HTTP στο εύρος IP που δίνετε.
- Οι γνωστές διευθύνσεις αποθηκεύονται τοπικά στον browser (όπου διατίθεται `localStorage`).

Για πιο συντηρητική παρακολούθηση στα Windows χρησιμοποιήστε τον [Windows Web Monitor v1.6.1](../Windows_Web_v1.6.1/README_GR.md). Ο HTML scanner είναι συμπληρωματικό εργαλείο. Κρατήστε τα miners και τις σελίδες παρακολούθησης μέσα σε αξιόπιστο ιδιωτικό δίκτυο.
