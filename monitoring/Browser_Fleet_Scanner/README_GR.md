# CRSminer Fleet Scanner — Οδηγίες στα ελληνικά

[Κεντρική σελίδα](../../README_GR.md) · [Άνοιγμα HTML αρχείου](CRSminer-Fleet-Scan.html)

Το **`CRSminer-Fleet-Scan.html`** είναι αυτόνομη σελίδα browser για παρακολούθηση τοπικού στόλου CRSminer. Προσφέρει εναλλαγή **Ελληνικών/Αγγλικών**, συνολικό hashrate, διαγράμματα, tiles miners και χειροκίνητη ανακάλυψη.

1. Κατεβάστε το αρχείο [CRSminer-Fleet-Scan.html](CRSminer-Fleet-Scan.html) και ανοίξτε το σε browser που επιτρέπει τις απαιτούμενες τοπικές HTTP κλήσεις.
2. Συνδεθείτε **στο ίδιο αξιόπιστο LAN** με τα ESP miners.
3. Προσθέστε/επιλέξτε τις γνωστές συσκευές και χρησιμοποιήστε τη χειροκίνητη λειτουργία σάρωσης **μόνο όταν χρειάζεται**.
4. Ελέγξτε τυχόν περιορισμούς browser **CORS**, μικτού περιεχομένου HTTP/HTTPS και δικτύου. Η λειτουργία μπορεί να εξαρτάται από browser/ασφάλεια και δεν εγγυάται ανακάλυψη σε κάθε περιβάλλον.
5. Μην εκτελείτε συνεχώς full subnet scans. Το HTML εργαλείο χρησιμοποιεί παράλληλη αναζήτηση και μπορεί να επιβαρύνει τους μικρούς ESP HTTP servers.

Για **προτεινόμενη συντηρητική παρακολούθηση στα Windows**, χρησιμοποιήστε τον [Windows Web Monitor v1.6.1](../Windows_Web_v1.6.1/README_GR.md). Ο HTML scanner είναι συμπληρωματικό εργαλείο και δεν αντικαθιστά τη σταθερή γέφυρα v1.6.1.

Οι διευθύνσεις wallet/IP είναι ευαίσθητα στοιχεία ιδιωτικότητας. Κρατήστε το dashboard και τις συσκευές εντός ιδιωτικού LAN.
