# CRS Mining Android Monitor — Εκδόσεις v1.2 και v1.3

[English](ANDROID_MONITOR_VERSIONS.md) · [Ελληνική αρχική σελίδα](../README_GR.md)

Το **Android Monitor/Scanner** είναι άλλη εφαρμογή από τον [Android CPU miner](../firmware/Android_CPU_Miner_v0.4/README_GR.md).

## v1.2 — προτεινόμενη λειτουργική έκδοση

[Πλήρες Android Studio project v1.2](Android_Monitor_v1.2/) · [Οδηγίες στα ελληνικά](Android_Monitor_v1.2/README_GR.md)

Είναι η έκδοση που **χρησιμοποιεί και έχει δοκιμάσει ο δημιουργός**. Στο Gradle δηλώνει `versionName '1.2'`, `versionCode 3` και application ID `com.hexohm.crsmining`.

- Ανακαλύπτει συμβατούς **ESP miners στη θύρα HTTP 80** στο τοπικό Wi-Fi/Ethernet subnet.
- Διαθέτει εναλλαγή ημέρας/νύχτας, πλακίδια 2/3/4 ανά σειρά, αποθηκευμένες IP και splash screen χωρίς επάνω status bar.
- **Δεν αναζητά** τον ξεχωριστό Android CPU miner στη θύρα **8080**.

## v1.3 — προαιρετικός πηγαίος κώδικας ανάπτυξης

[Πλήρες Android Studio project v1.3](Android_Monitor_v1.3/) · [Οδηγίες στα ελληνικά](Android_Monitor_v1.3/README_GR.md)

Η έκδοση αυτή **δεν έχει εγκατασταθεί ή δοκιμαστεί από τον δημιουργό** και **δεν αντικαθιστά την προτεινόμενη v1.2**. Προορίζεται για όσους θέλουν να μεταγλωττίσουν και να δοκιμάσουν τις αλλαγές:

1. Εξερεύνηση **80 (ESP32)** και **8080 (Android CPU miner)**.
2. Κλείσιμο TCP probe πριν από το HTTP `GET /api/status`, ώστε να μην κρατιέται η σύνδεση ανοιχτή κατά το επόμενο αίτημα.
3. Συμπερίληψη της **ίδιας της LAN IP του κινητού** στην αναζήτηση, όταν miner και monitor τρέχουν στην ίδια συσκευή.

Στο Gradle αναγράφεται `versionName '1.3-compat-dev'`, `versionCode 4`. **Γνωστή ασυμφωνία στο UI:** το παράθυρο About εξακολουθεί να εμφανίζει **Version 1.2**· δεν έχει διορθωθεί στον κώδικα ανάπτυξης.

Και οι δύο εκδόσεις χρησιμοποιούν **το ίδιο application ID**. Η εγκατάσταση δοκιμαστικής v1.3 μπορεί να αντικαταστήσει την v1.2 ή να μπλοκαριστεί από διαφορετική υπογραφή APK. **Κρατήστε backup της λειτουργικής v1.2 πριν πειραματιστείτε**.

## Build και δίκτυο

Ανοίξτε στο Android Studio τον αντίστοιχο φάκελο που περιέχει `settings.gradle`. Ακολουθήστε το `PREPARE_WINDOWS.bat` και τις ειδικές οδηγίες κάθε έκδοσης. Δοκιμάστε μόνο σε αξιόπιστο τοπικό LAN· απομόνωση Wi-Fi clients, firewall και οι πολιτικές Android μπορούν να εμποδίσουν την ανακάλυψη. Δεν περιλαμβάνεται επιβεβαιωμένο υπογεγραμμένο APK της v1.3.
