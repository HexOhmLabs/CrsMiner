# Android Monitor v1.3 — Σημειώσεις επιδιόρθωσης build

[Αγγλικό πρωτότυπο](FIX_404_README.txt) · [Πλήρης οδηγός πειραματικής v1.3](README_GR.md)

Το project περιλαμβάνει διορθώσεις για προβλήματα λήψης Gradle wrapper (HTTP 404). Εκτελέστε το `PREPARE_WINDOWS.bat` σε Windows πριν το Android Studio και ελέγξτε την επιτυχία της προετοιμασίας. Το συγκεκριμένο αρχείο αφορά **μόνο** το build setup, όχι επιβεβαίωση ότι οι αλλαγές discovery της v1.3 λειτουργούν. Διατηρήστε την εγκεκριμένη v1.2, επειδή η v1.3 δεν έχει δοκιμαστεί από τον δημιουργό.
