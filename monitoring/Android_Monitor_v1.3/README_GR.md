# CRS Mining Android Monitor v1.3 — Πειραματικός πηγαίος κώδικας

[English](README.md) · [Σύγκριση v1.2/v1.3](../ANDROID_MONITOR_VERSIONS_GR.md)

**Προσοχή: η v1.3 είναι έκδοση ανάπτυξης και δεν έχει δοκιμαστεί από τον δημιουργό.** Η [v1.2](../Android_Monitor_v1.2/README_GR.md) παραμένει η προτεινόμενη, επιβεβαιωμένα λειτουργική εφαρμογή.

## Σκοπός της v1.3

Ο πηγαίος κώδικας περιλαμβάνει τα αρχεία **`MinerClient.java`** και **`NetworkLocator.java`** με τις εξής αλλαγές:

- Αναζήτηση τόσο στη **θύρα 80** (ESP32) όσο και στη **θύρα 8080** (Android CPU miner).
- Κλείσιμο του αρχικού TCP socket πριν από το HTTP `/api/status`, για αποφυγή διπλής ταυτόχρονης σύνδεσης σε απλό single-client server.
- Συμπερίληψη της IP του ίδιου του κινητού, ώστε να μπορεί να ανακαλύψει τον Android CPU miner στην ίδια συσκευή.

Το Gradle δηλώνει `versionName 1.3-compat-dev`, `versionCode 4`, package `com.hexohm.crsmining`. **Γνωστό θέμα:** στο παράθυρο About μπορεί ακόμη να εμφανίζεται «Version 1.2». Δεν αλλάξαμε αυθαίρετα το UI της δοκιμαστικής έκδοσης.

## Build (Windows + Android Studio)

1. Χρησιμοποιήστε **ξεχωριστό αντίγραφο** του φακέλου v1.3, όχι αυτόν της σταθερής v1.2.
2. Εκτελέστε το παρεχόμενο **`PREPARE_WINDOWS.bat`** και ακολουθήστε το `README.md` για εξαρτήσεις Gradle, Android SDK και Android Studio.
3. Ανοίξτε με **Open** τον φάκελο που περιλαμβάνει `settings.gradle`, συγχρονίστε και μεταγλωττίστε σε debug APK.
4. Δοκιμάστε στο ίδιο αξιόπιστο Wi-Fi με έναν συμβατό ESP στη 80 και, προαιρετικά, τον Android CPU miner στη 8080.
5. Συγκρίνετε συμπεριφορά discovery, ενημερώσεις tiles και τυχόν επιβάρυνση των ESP. Αναφέρετε προβλήματα με logs χωρίς πραγματικές IP, MAC ή προσωπικές διευθύνσεις wallet.

## Προσοχή πριν την εγκατάσταση

Οι v1.2 και v1.3 έχουν **το ίδιο application ID**. Μία build της v1.3 ενδέχεται να αντικαταστήσει τη v1.2 ή να μην εγκατασταθεί αν η υπογραφή είναι διαφορετική. **Φυλάξτε τη λειτουργική v1.2**. Δεν υπάρχει επιβεβαιωμένο υπογεγραμμένο release APK v1.3 στο repository.

Η εφαρμογή κάνει monitoring **μόνο με ανάγνωση**· δεν ξεκινά/σταματά ούτε ρυθμίζει απομακρυσμένα miners. Μην εκθέτετε endpoints HTTP στο δημόσιο Internet και αποφύγετε συνεχείς πλήρεις σαρώσεις δικτύου.
