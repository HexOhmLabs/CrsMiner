# Android Monitor v1.2 — Σημειώσεις επιδιόρθωσης build

[Αγγλικό πρωτότυπο](FIX_404_README.txt) · [Πλήρης οδηγός v1.2](README_GR.md)

Το παλαιότερο πακέτο παρουσίαζε σφάλμα λήψης (**HTTP 404**) για το Gradle wrapper. Η τωρινή διανομή περιλαμβάνει τις διορθωμένες υποδομές build και το script `PREPARE_WINDOWS.bat`. Εκτελέστε το στον φάκελο project σε Windows, ελέγξτε ότι ολοκληρώνεται, έπειτα ανοίξτε το project με Android Studio. Μην αλλάζετε αυθαίρετα Gradle/Android Gradle Plugin. Σε νέο σφάλμα ελέγξτε το πρώτο μήνυμα στο Gradle Sync και ακολουθήστε το αγγλικό τεχνικό αρχείο για τις ακριβείς λεπτομέρειες.
