# CRS Mining Android Monitor v1.2 — Ελληνικός οδηγός

[English](README.md) · [Σύγκριση v1.2/v1.3](../ANDROID_MONITOR_VERSIONS_GR.md)

**Προτεινόμενη, δοκιμασμένη από τον δημιουργό έκδοση.** Εφαρμογή **παρακολούθησης** των ESP CRSminer, **όχι** εφαρμογή που κάνει mining. Package `com.hexohm.crsmining`, `versionName 1.2`, `versionCode 3`.

## Λειτουργίες

- Σύνδεση απευθείας με API ESP στο **τοπικό Wi-Fi/Ethernet**, **θύρα HTTP 80**, χωρίς εξωτερικό λογαριασμό/cloud.
- Splash HexOhm τεσσάρων δευτερολέπτων και **κρυμμένη επάνω status bar** όσο η εφαρμογή είναι ανοιχτή.
- Αναζήτηση μέχρι **1.024 υποψήφιες IP** σε μεγάλα υποδίκτυα και έλεγχος ότι κάθε συσκευή έχει τη σωστή CRSminer API υπογραφή.
- Πλακίδια με miner hostname/worker, hashrate, μικρό διάγραμμα, accepted/rejected shares, pool και διεύθυνση wallet. Τα μεγάλα wallet strings συντομεύονται μόνο στην εμφάνιση.
- Πράσινο = λειτουργεί και κάνει mining, πορτοκαλί = προσοχή, κόκκινο = εκτός σύνδεσης ή κρίσιμο διαγνωστικό.
- Σύνολο στόλου, εναλλαγή Day/Night και **2, 3 ή 4 πλακίδια ανά σειρά**.
- Ανανέωση κάθε **5 δευτερόλεπτα** όσο εμφανίζεται η εφαρμογή και χειροκίνητο ↻ για νέα αναζήτηση.
- Πάτημα πλακιδίου: αναλυτικές ενδείξεις uptime, difficulty, RSSI, θερμοκρασίας, SHA mode, jobs και σφαλμάτων· δυνατότητα ανοίγματος του αρχικού dashboard του miner.
- Αποθηκεύονται **μόνο οι IP** για γρήγορη επανασύνδεση, όχι wallets, εργαζόμενοι ή κωδικοί.

## Εγκατάσταση από πηγαίο κώδικα (Windows)

1. Αποσυμπιέστε τον φάκελο του project και ανοίξτε τον στα Windows.
2. Εκτελέστε **`PREPARE_WINDOWS.bat`**: αποκτά τον επίσημο Gradle wrapper JAR και ελέγχει checksum. Χρειάζεται Internet και PowerShell.
3. Στο **Android Studio → Open** επιλέξτε τον φάκελο με `settings.gradle` και `gradlew.bat`.
4. Το αρχικό project χρησιμοποιεί **Gradle 9.5.0**, **Android Gradle Plugin 9.3.0**, **SDK Platform 37** και συμβατό JDK (οδηγία βάσης **JDK 17**). Εγκαταστήστε τις ελλείπουσες εξαρτήσεις μέσω SDK Manager.
5. Μετά το Gradle Sync, επιλέξτε **Build → Build Bundle(s)/APK(s) → Build APK(s)** και βρείτε το `app/build/outputs/apk/debug/app-debug.apk`.
6. Περάστε το debug APK στο κινητό και δώστε, αν ζητηθεί, άδεια εγκατάστασης από τη συγκεκριμένη πηγή. Συνδέστε το κινητό στο ίδιο δίκτυο με τους ESP miners.

Το repository παρέχει πηγαίο κώδικα, όχι έτοιμο υπογεγραμμένο APK. Δεν έγινε ανεξάρτητο build σε Android Studio στο περιβάλλον δημιουργίας της τεκμηρίωσης.

## Χρήση και ασφάλεια

1. Ανοίξτε το monitor στο Wi-Fi του στόλου. Χρησιμοποιήστε ↻ για ανακάλυψη ή τις αποθηκευμένες συσκευές.
2. Πατήστε πλακίδιο για λεπτομέρειες. Οι μετρήσεις προέρχονται από `/api/status` και `/api/config`, **μόνο με GET**. Το monitor **δεν** αλλάζει ρυθμίσεις και **δεν** επανεκκινεί miners.
3. Ο scanner v1.2 **δεν αναζητά τη θύρα 8080**, όπου λειτουργεί το ξεχωριστό Android CPU miner. Για δοκιμές αυτής της δυνατότητας υπάρχει ο [πηγαίος κώδικας v1.3](../Android_Monitor_v1.3/README_GR.md).
4. Σε Android 17 / target API 37 μπορεί να απαιτείται δικαίωμα **`ACCESS_LOCAL_NETWORK`**. Οι πολιτικές εξαρτώνται από την έκδοση Android.
5. Χρησιμοποιήστε **αξιόπιστο ιδιωτικό LAN**. Η εφαρμογή δεν ελέγχει το Internet ούτε το cellular δίκτυο, και το HTTP των ESP δεν έχει authentication.

## Ιστορικό

Η v1.1 βελτίωσε την εμφάνιση **MINING** όταν υπάρχει παλιό `err`, χωρίς να κρύβονται τα τρέχοντα διαγνωστικά. Η v1.2 απέκρυψε την επάνω Android status bar μέσω `android:windowFullscreen`, χωρίς αλλαγή στη λειτουργία mining/monitoring.
